# OrderFlow (OmniArab) — منصة موحّدة لإدارة متاجر أمازون مصر ونون وجوميا

**OrderFlow** هي منصة سحابية متكاملة باللغة العربية (RTL) لمساعدة التجار والشركات في مصر على إدارة متاجرهم على **أمازون مصر (Amazon.eg)** و**نون (Noon)** و**جوميا (Jumia)** من لوحة تحكم واحدة بالجنيه المصري.

تعتمد المنصة على معمارية خفيفة وسريعة بدون أطر عمل خارجية ثقيلة:
- **الخادم (Backend):** Node.js قياسي (`node:http`، `node:sqlite` بوضع WAL، `node:crypto`) مع جلسات موقّعة بـ HMAC وحماية CSRF (`X-Requested-With: omniarab` + فحص `Origin`) وتحديد معدل الطلبات (Rate Limiting).
- **الواجهة الأمامية (Frontend):** Vanilla JavaScript (`public/js/app.js`) مع موجه مسارات يدعم المسارات المتداخلة (`#/admin/clients/12`)، وتصميم عربي متجاوب (`public/css/app.css`).
- **الذكاء الاصطناعي:** تكامل اختياري مع Google Gemini (`@google/genai`) لكتابة محتوى المنتجات، أبحاث السوق المصري، والمستشار الاستراتيجي، مع قوالب احتياطية فورية عند غياب المفتاح.

## المزايا الرئيسية

### ١. لوحة تحكم التاجر (Merchant Dashboard)
- **إدارة الكتالوج والمخزون الموحّد:** إضافة وتعديل المنتجات مع الصور والأيقونات الجاهزة، عرض حالة الاعتماد (`قيد المراجعة` / `معتمد` / `مرفوض` مع سبب الرفض)، وتصدير واستيراد CSV.
- **الطلبات والفواتير الضريبية:** تسجيل الطلبات، تحديث حالاتها (`قيد التجهيز`، `مع شركة الشحن`، `تم التسليم`، `مرتجع`، `ملغى` مع استرجاع المخزون تلقائيًا)، طباعة الفواتير الضريبية المبسطة (١٤٪ ضريبة القيمة المضافة مع QR) وبوالص الشحن المجمّعة (AWB).
- **إدارة المرتجعات (RTO):** صفحة مخصصة لتحليل الطلبات المرتجعة وتسجيل وتعديل سبب الارتجاع لكل شحنة.
- **قاعدة بيانات العملاء (CRM):** سجل موحّد لعملاء المتجر مجمّع حسب رقم الهاتف أو الاسم مع إجمالي الإنفاق وعدد الطلبات الناجحة والمرتجعة/الملغاة.
- **تحصيلات الدفع عند الاستلام (COD) والتقارير المالية:** متابعة أرصدة بوسطة وأرامكس ومايلز وميلرز وطلب التحويل إلى InstaPay، وحاسبة هامش الربح الصافي بعد عمولات الأسواق وضريبة القيمة المضافة ونسبة المرتجعات.
- **مركز الإشعارات ومركز المساعدة:** إشعارات فورية باعتماد أو رفض المنتجات والطلبات، ومركز مساعدة تفاعلي مع إمكانية فتح تذاكر دعم فني.
- **الأمان وإدارة الحساب:** استعادة كلمة المرور برمز مؤقت صالح لمرة واحدة، وتوثيق البريد الإلكتروني عبر نظام بريد معياري (`src/mailer.js`) يطبع الرسائل في الطرفية أثناء التطوير.

### ٢. لوحة تحكم الإدارة (Admin Portal — `#/admin`)
- **إحصائيات المنصة الشاملة:** إجمالي التجار، الحسابات النشطة والموقوفة، العناصر المعلقة للمراجعة، وإجمالي اشتراكاتOrderFlow Pay.
- **إدارة التجار (`#/admin/clients` و `#/admin/clients/:id`):** البحث والتصفية، عرض تفاصيل التاجر ومنتجاته وطلباته ومدفوعاته، إيقاف الحساب أو إعادة تفعيله (الحساب الموقوف يُمنع من تسجيل الدخول وتُلغى جلساته فورًا)، وتغيير باقة الاشتراك.
- **التصفح بوضع القراءة فقط (Read-only Impersonation):** إمكانية دخول المشرف إلى لوحة تحكم أي تاجر لمعاينة حسابه بدون صلاحية تعديل أي بيانات، مع تسجيل العملية في سجل التدقيق.
- **طابور الاعتمادات (`#/admin/approvals`):** مراجعة المنتجات والطلبات الجديدة التي أضافها التجار؛ العناصر المعتمدة فقط تُحتسب في المخزون الفعلي وتدخل في عمليات المزامنة (`/api/sync`)، وعند الرفض يُشترط كتابة سبب يظهر للتاجر.
- **المدفوعات والكوبونات (`#/admin/payments` و `#/admin/coupons`):** متابعة كافة عمليات الدفع وإدارة كوبونات الخصم المخزنة في قاعدة البيانات (إضافة، تعديل، تفعيل/إيقاف، حذف).
- **سجل التدقيق الأمني (`#/admin/audit`):** توثيق كامل لكل إجراء إداري بالتاريخ والمشرف والتفاصيل.

### ٣. الصفحات العامة والقانونية
- صفحات عامة متاحة للجميع ومرتبطة بتذييل الموقع: **عن المنصة (`#/about`)**، **الشروط والأحكام (`#/terms`)**، **سياسة الخصوصية (`#/privacy`)**، **سياسة الاسترداد (`#/refund`)**، **تواصل معنا (`#/contact`)**، بالإضافة إلى صفحة **404** حقيقية للمسارات غير الموجودة.

## متغيرات البيئة (Environment Variables)

| المتغير | الوصف | القيمة الافتراضية |
|---|---|---|
| `PORT` | منفذ تشغيل خادم HTTP | `3000` |
| `DATA_DIR` | مسار حفظ قاعدة بيانات SQLite (اختياري) | مجلد مؤقت للنظام |
| `SESSION_SECRET` | مفتاح توقيع الجلسات وروابط الإيصالات (٣٢ حرفًا على الأقل في الإنتاج) | يُولَّد تلقائيًا في التطوير |
| `ADMIN_PHONE` | رقم موبايل المشرف الأول الذي يُنشأ أو يُرقّى تلقائيًا عند بدء التشغيل | — |
| `ADMIN_PASSWORD` | كلمة مرور المشرف الأول (٨ أحرف على الأقل) | — |
| `GEMINI_API_KEY` | مفتاح Google Gemini لتشغيل أدوات الذكاء الاصطناعي الحقيقية | — (يعمل الوضع الاحتياطي بدونه) |
| `PAYMENT_PROVIDER` | مزود بوابة الدفع (`sandbox` للتجربة أو `hosted` للربط الحقيقي) | `sandbox` |

## هيكل المشروع

```text
├── server.js                 # نقطة تشغيل الخادم وتحميل متغيرات البيئة
├── src/
│   ├── app.js                # تهيئة التطبيق، الموجهات، حماية الجلسات، وإنشاء المشرف الأول
│   ├── auth.js               # تشفير كلمات المرور، توقيع الجلسات، التصفح بوضع القراءة، وحارس المشرف
│   ├── config.js             # إعدادات البيئة والحدود الافتراضية
│   ├── db.js                 # مخطط SQLite والترحيلات التلقائية (Migrations 1–4)
│   ├── domain.js             # الثوابت وقواعد الأعمال وحساب العمولات والاشتراكات
│   ├── http.js               # أدوات HTTP، ترويسات الأمان، وفحص CSRF ومعدل الطلبات
│   ├── mailer.js             # نظام إرسال البريد المعياري (Console Mailer في التطوير)
│   ├── model.js              # محولات الكائنات والاستعلامات المشتركة
│   ├── pages.js              # قوالب HTML المطبوعة (الفواتير الضريبية، البوالص، الإيصالات)
│   ├── seed.js               # البيانات التجريبية الأولية
│   ├── util.js               # دوال التحقق والتنسيق المساعدة
│   ├── payments/             # مزودات بوابة الدفع (sandbox / hosted)
│   └── routes/               # مسارات الـ API (auth, catalog, orders, finance, account, billing, ai, admin)
├── public/
│   ├── index.html            # صفحة HTML الرئيسية (RTL)
│   ├── css/app.css           # تنسيقات الواجهة والوضع الليلي والطباعة
│   └── js/app.js             # تطبيق الواجهة الأمامية وموجه المسارات
└── test/
    └── api.test.js           # اختبارات التكامل الشاملة (node:test)
```
